# IC Balance Viewer v5【最終版】（New 3DS 用・交通系IC残高ビューア）

製作者： pica200san
リポジトリ： https://github.com/pica-nihyaku-san/ic-balance-viewer-3ds

New Nintendo 3DS LL（日本モデル）内蔵の FeliCa リーダーで、交通系ICカードの
**残高と利用履歴（直近20件・駅名表示つき）を表示するだけ** のアプリです。
決済機能はありません。カードへの書き込みも一切しません
（駅の残高確認機と同じ、認証不要の読み取り専用領域を読むだけです）。

## v5 の変更点（2026-11-14、実機フィードバックを受けて）
- v4 のカード切り替えが実機で動作しなかった問題を修正。原因は、読み取り済み
  セッションの中で新しいタグを検知し直そうとしていたこと（実機では新しい
  タグを取り直せない）。v5 ではカードが離れたら **スキャンセッションを
  止めて張り直し**（v1 から実証済みの stop/start サイクル）、表示は旧カード
  のまま維持して、新しいカードが来たら読み取って切り替える。Bボタン不要で
  自動で切り替わる

## v4 の変更点（2026-11-14、実機フィードバックを受けて）
- 結果画面の出しっぱなし化：**カードを離しても履歴は表示されたまま**。
  待機画面へは **Bボタン** で戻る（従来はカードを離すと自動で戻っていた）
- 表示中に **別のカードをかざすと、そのカードの内容に表示を切り替え**
  （カードの離脱→新しいカードの接近を検知して再読み取り。
  切り替え読み取りに失敗した場合は前の表示を保持する）
- ついでにバス履歴の行にも「残 ¥…」を表示するよう統一

## v3 の変更点（2026-11-14）
- **バナーを追加**：HOMEメニューで上画面に出るやつ。256×128のデザイン画像
  （`banner/banner.png`）＋短いチャイム音（`banner/banner.wav`）入り。
  bannertool を入手できたので実現（下記ビルドメモ参照）
- アプリ本体は v2 と同一（version だけ 3 に更新。上書きインストール可能）

## v2 の変更点（2026-11-13）
- 画面を全面作り替え：citro2d 描画の「カード風」デザイン（デザインA）、
  本体内蔵フォントによる **日本語表示**、残高の大きな数字表示
- **駅名変換**：履歴の駅コードを駅名で表示（例：`函館本線 札幌 → 発寒`）。
  駅名DBは全国 5,834 駅（SFCardFan 系 StationCode.csv 由来）を RomFS に内蔵
- アイコンを専用デザインに変更、タイトルも日本語「IC残高ビューア」に
- 読み取り処理（NFC/FeliCa）は v1 で実機実証済みのコードと同一

## 駅名DBの差し替え
SDカードの `sdmc:/ic-balance/stations.bin` があれば、そちらを優先して
読みます（アプリを再インストールせずにDBだけ更新可能）。
DBの生成は `db/convert.py`（StationCode.csv → stations.bin）。

## 操作
- 起動したらカードを下画面にかざす → 残高＋履歴が表示される
- 下画面の履歴は 十字キー↑↓ でスクロール
- **カードを離しても表示はそのまま**（じっくり読める）。
  別のカードをかざせばそのカードに切り替わる
- 待機画面に戻る：Bボタン ／ 終了：START

## ビルドメモ
- devkitPro（libctru + citro2d）で `make` → .3dsx / .elf / .smdh
- CIA: makerom `-f cia -rsf icbalance.rsf -elf … -icon … -banner banner/banner.bin -ver 6`
  （RomFS は RSF 末尾の `RomFs: RootPath: "romfs"` で取り込む。
  `-romfs` オプションに mkromfs3ds の出力を渡すと Invalid RomFS Binary になる）
- bannertool: 本家 Steveice10 の GitHub リポジトリは削除済み。バックアップ
  carstene1ns/3ds-bannertool（CMake版）を自前ビルドして使用。バナー生成は
  `bannertool makebanner -i banner/banner.png -a banner/banner.wav -o banner/banner.bin`
- v1 のコードはこのリポジトリのコミット履歴に残っています（`poc/` は
  先行検証用 PoC のソース）
